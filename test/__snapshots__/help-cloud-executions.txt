List executions for a cloud schedule

USAGE
  $ rrulenet cloud executions ID [--json] [--limit <value>] [--offset <value>]

ARGUMENTS
  ID  Cloud schedule id or unique prefix

FLAGS
  --limit=<value>   Maximum executions to return (1-100)
  --offset=<value>  Executions to skip (zero or greater)

GLOBAL FLAGS
  --json  Format output as json.

EXAMPLES
  $ rrulenet cloud executions abcd1234

  $ rrulenet cloud executions abcd1234 --limit 25 --offset 25

  $ rrulenet cloud executions abcd1234 --json
